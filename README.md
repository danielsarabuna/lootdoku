## 🎮 Gameplay Overview

1. **Place Figures**: Drag and drop figures from the bottom tray onto the grid.
2. **Clear Lines**: Complete horizontal or vertical lines to clear them and score points.
3. **Rotate**: Rotate available shapes before placing them.
4. **Game Over**: The game ends when none of the available shapes can fit onto the board.

---

## ⌨️ Controls

- **Left Mouse Button (Drag & Drop)** — Move shape onto the board
- **`R` Key** — Rotate shape
- **`Esc` Key** — Pause menu
